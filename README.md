# Malfoid: The Girl who Yearned

The public reader for *Malfoid*, a free, non-commercial fan webcomic. It retells *Harry Potter and the Philosopher's Stone* with a split point of view between Harry Potter and Draconia Malfoy.

This repository holds only the reader: the site, the cover and the published panels. The working files (script, character sheets, notes) live in a separate private repository.

## Notes for readers

- Fan work. Harry Potter, its characters and settings belong to J. K. Rowling and the rights holders. This comic is not affiliated with or endorsed by them.
- Made with AI image tools, panel by panel, and lettered by hand. Each chapter notes how its images were made.
- Pages are read in order, top to bottom.

## Layout

- `index.html`: the landing page and chapter list.
- `chapters/index.json`: the chapter list the landing page reads.
- `chapters/<id>/`: one folder per chapter, with `index.html` and `img/` for its panels.
- `cover.jpg`: the title cover.
- `.nojekyll`: tells GitHub Pages to serve the files as they are.

## Publishing

GitHub Pages serves the `main` branch from the repository root. Chapter images are copied in from the private build; nothing here is generated by hand.
